新規事業の甲子園 — 表彰式 改善版

【起動】
ZIPをすべて展開し、index.html をChromeまたはEdgeで開いてください。
index.html / script.js / style.css は同じフォルダに置きます。
Three.jsとフォントは同梱済みで、外部CDNへの接続は不要です。

【本番前の準備】
1.「大会設定」で大会名・開催年・各賞のチーム名・事業名を入力。
2.「保存して準備完了」を押すと冒頭へ戻ります。
3. 必要な場合のみ「音 OFF」を押してONにします。音量はPC側で調節。
4. 右上の全画面ボタン、またはFキーで全画面に切り替え。
5. 本番のPC・投影機・音響で全シーンを通してリハーサルしてください。

【進行】
冒頭 → 3位予告 → 3位発表 → 準優勝予告 → 準優勝発表 → 優勝予告 → 優勝発表
Space / → / ↓ / PageDown：次へ
← / ↑ / PageUp：前へ
R：冒頭へ
F：全画面切り替え
各予告で司会に合わせて待機できます。発表操作の後、約1.65秒ためて受賞名を表示。
演出中は連打を受け付けません。優勝発表後は自動で戻りません。
スクロールでは進行しないため、誤操作を防げます。
音はブラウザで合成する短い効果音です。楽曲や歓声の録音は含みません。

【入力と保存】
入力値は同じブラウザのローカル保存を使用します。別PCには自動転送されません。
保存が制限される環境では画面を開いている間のみ有効です。
別PCへの配布時に初期値を固定する場合は、index.html末尾のAWARDS_CONFIGを編集してください。
画面内の日本語大会名は変更できます。3D英字ロゴはDIAMOND AWARDSです。

【表示環境】
WebGL対応のChrome / Edgeを想定。PCの横長画面での投影を推奨。
OSの「視差効果を減らす」設定時は、動きを短縮し紙吹雪を停止します。
構文チェック済み。作成環境では検証ブラウザの取得ができなかったため、
実ブラウザでの描画・音響の最終確認は未実施です。
