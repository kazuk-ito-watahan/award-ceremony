THE LAST PITCH — 新規事業の甲子園 表彰式

今回は3Dシーンと進行制御を新規実装しています。
既存の画面レイアウト・大会設定・操作方法は維持しています。

【起動】
ZIPをすべて展開し、index.html をChrome / Edgeで開いてください。
index.html・script.js・style.cssを同じフォルダに置いてください。
Three.js・英数字フォント・日本語フォントを同梱し、外部CDNには接続しません。
映像、写真、録音素材は使用せず、形状・質感・短い効果音をプログラムで生成しています。

【新しい演出】
・最後の一球：革目、縫い溝、108組の赤い縫い目を持つ白球
・夜のグラウンド：土、白線、薄い霧、遠景の照明と光の筋
・銅・銀・金：立体の順位数字と細い装飾リング
・優勝：深紅の織物風の旗、風による変形、金色の紙吹雪
実在の甲子園球場の正確な建築モデルではなく、甲子園をテーマにした演出です。

【進行】
冒頭 → 3位予告 → 3位発表 → 準優勝予告 → 準優勝発表 → 優勝予告 → 優勝発表
Space / → / ↓ / PageDown：次へ
← / ↑ / PageUp：戻る
R：冒頭へ
F：全画面
予告で司会に合わせて待機できます。発表ボタンの後、約1.65秒で受賞名が現れます。
演出中は連打を防止しています。優勝後はその画面を保持します。

【設定】
大会設定から大会名・開催年・各賞のチーム名と事業名を編集できます。
設定は同じブラウザのローカル保存を使います。別PCには自動転送されません。
別PCでも初期値を固定する場合は index.html のAWARDS_CONFIGを変更してください。
音は初期状態でOFFです。ONにしてからPC側の音量で調節してください。
本番の投影機で文字サイズ・明るさ・音量を確認してください。

【表示と検証】
Chromiumでfile://からの起動と全7段階の進行を確認しています。
OSの「視差効果を減らす」設定時は動きを短縮し、紙吹雪を停止します。
本番のPC・GPU・投影環境でのフレームレートと実音量は別途ご確認ください。

【ソース】
source/main.js が編集用のコードです。
再ビルドする場合はNode.jsを用意してsourceフォルダ内で npm install → npm run build。
表示するだけならNode.jsやインストール操作は不要です。
日本語フォントはstyle.css内に埋め込み済みです。
ライセンスはlicensesフォルダに同梱しています。
